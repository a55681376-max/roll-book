# 노인복지관 배움터 전자출석부 시스템

> **소라색(Sora Blue) 배움터 테마**와 **동글동글 통통한 책·연필 이모티콘**, **직원 관리자 암호 보안 체계**가 적용된 완성형 전자출석부 웹 애플리케이션입니다.

---

## 🎨 주요 디자인 및 기능 개선 사항

### 1. 맑고 포근한 소라색(Sora Blue) 팔레트 적용
- **메인 컬러 (소라색 `#4fa8ea`)**: 주요 액션 버튼, 출석 타일, 인터랙션 포인트
- **소라색 그림자 3D 효과 (`#3488c5`)**: 스티커처럼 푹신하게 눌리는 입체 버튼
- **부드러운 소라색 틴트 워시 (`#eef6fd`, `#d8ecfc`)**: 배경 및 하이라이트 뱃지
- **딥 소라색 (`#1e6fae`)**: 시인성 높은 헤드라인 및 포인트 텍스트

### 2. 동글동글 통통하고 귀여운 책·연필(📚✏️) 마스코트
- 기존 부엉이 대신 복지관 배움터 느낌의 귀여운 **책과 연필(`📚`, `✏️`, `📖`)** 이모티콘 적용
- 어르신들이 즐겁게 참여하실 수 있는 따뜻하고 친근한 배움터 비주얼

### 3. 강사 출석관리 탭 삭제 및 메뉴 구조 단순화
- 불필요했던 강사 전용 탭을 제거하고, 상단을 **[✍️ 참여자 출석 (키오스크)]**와 **[🔒 직원 (관리자)]** 2단계로 단순화
- 강사가 담당하던 대리 서명 지원 및 결석 체크 기능은 **직원 관리자 화면의 '3. 출석 현황 & 결석 처리' 서브탭**에서 편리하게 통합 지원

### 4. 직원 관리자 비밀번호 로그인 및 암호 변경 기능
- **관리자 접근 보안**: 어르신이나 일반인이 관리자 설정에 접근하지 못하도록 **암호 인증 팝업** 제공
- **기본 비밀번호**: `1234`
- **암호 변경 기능**: 관리자 모드 진입 후 상단의 **[🔑 암호 변경]** 버튼을 통해 언제든 비밀번호를 변경하여 안전하게 보관 가능
- **관리자 로그아웃**: 작업 완료 후 **[🚪 관리자 로그아웃]** 버튼을 누르면 일반 키오스크 모드로 안전 복귀

## 📌 핵심 기능 안내 (PRD v0.1 규격 준수)

1. **✍️ 어르신 친화적 참여자 키오스크**
   - 큼직한 이름 타일 ➔ **"OOO 님이 맞으신가요?" 본인 확인** ➔ **대형 캔버스 전자서명 (터치/마우스/펜)** ➔ 출석 완료
   - **동명이인 구분**: 이름이 같은 참여자가 있을 경우 회원번호를 자동으로 병기하여 오서명 방지
2. **⚙️ 직원 관리자 통합 제어**
   - **프로그램 & 회차 관리**: 기간/요일 기반 **회차 자동 생성**, 개별 날짜 수정, **휴강일 지정**(실제 운영 회차 및 출석률 계산에서 자동 제외)
   - **참여자 관리**: 개별 등록 및 **Excel(.xlsx/.csv) 일괄 등록**, 엑셀 양식 다운로드, 비회원 지원, **중도포기 관리**
   - **출석 현황 & 결석 처리**: 당일 출석/결석 현황 대시보드, 서명 돕기, 결석 처리/취소
   - **A4 출석부 생성 & 인쇄**: 자유로운 출력 범위(전체, 월별, 회차 범위), 항목 선택(연락처/회원번호/출석률 표시 토글), **페이지당 6회차 단위 자동 분할**, 실제 서명 이미지 포함, **중도포기자 하단 자동 배치**
3. **출석률 자동 계산 공식**:
   $$\text{출석률} = \frac{\text{출석한 회차}}{\text{프로그램 전체 실제 운영 회차 (휴강 제외)}} \times 100$$

## 🚀 실행 방법

1. 폴더 안의 **`index.html`** 파일을 더블 클릭합니다.
2. 브라우저(Chrome, Edge, Safari, 태블릿 등)에서 즉시 동작합니다.
3. 기본으로 **'테스트 프로그램'** 및 **'홍길동'**, **'김철수'**, **'이영희'** 등의 참여자 샘플 데이터가 등록되어 있어 바로 테스트할 수 있습니다.
4. 직원 관리자 모드 진입 시 비밀번호 **`1234`**를 입력하시면 됩니다.
5. 데이터는 브라우저 `localStorage`에 자동 보관되며, 우측 상단 **[백업]** 버튼으로 JSON 파일 다운로드 및 **[복원]**이 가능합니다.
