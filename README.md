# 노인복지관 전자출석부

브라우저에서 사용하는 전자출석부입니다. 프로그램, 참여자, 전자서명, 출석 기록과 A4 인쇄를 지원합니다.

## 화면 사용 방법

1. 첫 화면에서 **담당자 인증** 또는 **관리자 인증**을 선택합니다.
2. 아이디와 비밀번호를 입력합니다.
3. 담당자 인증 후에는 **참여자 출석** 화면이 열립니다. 참여자가 이름을 선택하고 서명합니다.
4. 상단 **담당자** 버튼을 누르고 다시 로그인하면 **프로그램 관리 / 참여자 관리 / 출석 관리 / 인쇄**를 사용할 수 있습니다.
5. **참여자 출석** 화면으로 돌아가면 담당자 관리 인증이 종료됩니다. 관리 화면에 다시 들어갈 때는 로그인해야 합니다.
6. **로그아웃**을 누르면 첫 화면으로 돌아갑니다. 새로고침한 경우에도 첫 화면에서 인증합니다.

## 관리자 설정

관리자 인증 후에는 **설정** 화면을 사용합니다.

- **담당자 계정 목록**: 담당자 계정을 확인하고 수정하거나 삭제합니다. 비밀번호는 목록에 표시하지 않습니다.
- **+ 새 담당자 등록**: 아이디, 비밀번호, 관리자 확인용 메모를 입력합니다. 메모는 선택 사항이며 담당자 화면에는 표시하지 않습니다.
- **관리자 계정 변경**: 아이디, 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력합니다. 현재 비밀번호가 맞아야 저장됩니다.

기존 계정과 출석 데이터는 그대로 사용합니다. 기존 최고 관리자 계정은 관리자, 기존 일반 관리자 계정은 담당자 역할로 사용합니다.
초기 관리자 계정은 master / master1234, 초기 담당자 계정은 admin / 1234입니다. 계정을 변경한 경우 변경된 계정으로 로그인합니다.

## 실행 및 배포

별도 빌드 없이 index.html을 브라우저에서 실행하거나 정적 웹사이트로 배포합니다.
GitHub main에 변경사항을 올리면 연결된 Netlify 프로젝트 rollbook1에 자동 배포됩니다.

## 데이터 저장

브라우저 localStorage에 저장하며, Supabase 연결 시 PostgreSQL의 attendance_data 테이블과 Realtime으로 동기화합니다.
새 Supabase 프로젝트를 사용할 경우 supabase_schema.sql을 SQL Editor에서 실행한 뒤 웹앱의 Supabase 설정에서 URL과 anon 키를 입력합니다.
현재 로그인은 브라우저 화면 접근을 제어하는 방식입니다. Supabase Auth를 통한 서버 인증은 구현되어 있지 않으며, 기존 SQL 정책은 익명 접근을 허용합니다.

## 사용 기술

HTML5, CSS3, Vanilla JavaScript, Canvas 전자서명, SheetJS 엑셀 처리, Supabase JS v2, localStorage.
