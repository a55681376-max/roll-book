# 📚 노인복지관 프로그램 전자출석부 시스템

> 노인복지관 프로그램 운영을 위한 **어르신 친화적 전자출석부 웹 애플리케이션**입니다.
> 별도 설치 없이 브라우저에서 즉시 실행되며, 태블릿·PC 모두 지원합니다.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| ✍️ **키오스크 출석** | 링크 접속 즉시 직관적인 어르신 전용 큰 글씨 이름 타일 → 본인 확인 → 전자서명 → 출석 완료 |
| 🛡️ **관리자 로그인** | 마스터 관리자 vs 일반 관리자 권한 분리 로그인 |
| 👑 **마스터 관리자 권한** | 소속 기관 정보 수정, 일반 관리자 계정(ID/PW) 등록·수정·삭제, 마스터 암호 관리 |
| 👤 **일반 관리자 권한** | 프로그램 개설 및 회차 관리, 참여자 엑셀 업로드, 출석/결석 처리, A4 출석부 인쇄 |
| 👥 **동명이인 구분** | 같은 이름의 참여자는 회원번호를 자동 병기하여 오서명 방지 |
| 📅 **회차 자동 생성** | 기간·요일 입력 시 회차를 자동으로 생성, 휴강일 지정 가능 |
| 👤 **참여자 관리** | 개별 등록 및 Excel(.xlsx/.csv) 일괄 등록, 중도포기 관리 |
| 📊 **출석 현황 대시보드** | 당일 출석/결석 현황, 대리 서명 보조, 결석 처리/취소 |
| 🖨️ **A4 출석부 인쇄** | 전체·월별·회차 범위 선택, 실제 서명 이미지 포함 출력 |
| 💾 **데이터 자동 저장** | 브라우저 localStorage 저장, JSON 백업·복원, Supabase 클라우드 실시간 동기화 |


- 링크에 접속하면 **어르신들이 바로 출석할 수 있는 키오스크 화면**이 즉시 열립니다.
- 상단 메뉴의 **`[🔒 직원 (관리자)]`** 탭을 클릭하여 관리자 모드로 로그인할 수 있습니다:

### 🛡️ 관리자 로그인 계정 (마스터 / 일반 관리자)
- **👑 마스터 관리자 (Master)**:
  - **아이디**: `master`
  - **비밀번호**: `master1234`
  - **권한**: 소속 기관명 설정, 일반 관리자 계정 추가/수정/삭제, 마스터 비밀번호 변경, 모든 프로그램 및 출석부 관리
- **👤 일반 관리자 (General Admin)**:
  - **아이디**: `admin`
  - **비밀번호**: `1234`
  - **권한**: 프로그램 운영 관리, 참여자 명단 관리, 당일 출석/결석 처리, A4 출석부 인쇄 (마스터 관리자 전용 메뉴는 숨김 처리)

## ⚡ 수파베이스 (Supabase) 클라우드 DB 연동 가이드

여러 대의 PC, 태블릿, 스마트폰에서 **출석 데이터를 실시간으로 동기화**하려면 Supabase를 1분 만에 연결할 수 있습니다:

1. **[Supabase](https://supabase.com)**에 로그인하고 새 프로젝트를 생성합니다.
2. 대시보드 좌측 **[SQL Editor]**로 이동하여 `supabase_schema.sql` 파일의 내용을 붙여넣고 **[Run]**을 실행합니다.
3. **[Project Settings] > [API]**에서 아래 2가지 값을 확인합니다:
   - `Project URL`
   - `anon` `public` API 키
4. 웹앱 우측 상단의 **[⚡ Supabase]** 버튼을 클릭하고 URL과 키를 입력한 뒤 **[저장 및 연결]**을 누르면 끝납니다!
5. **실시간 양방향 동기화**: 다른 기기에서 출석 서명 시, 열려 있는 모든 관리자/키오스크 화면에 즉각 실시간 반영됩니다.

## 💡 기술 스택

- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript (단일 파일)
- **Database & Sync**: [Supabase (PostgreSQL + Realtime)](https://supabase.com/) & 브라우저 `localStorage` (하이브리드 지원)
- **Excel 처리**: [SheetJS (xlsx)](https://sheetjs.com/) CDN
- **서명**: HTML5 Canvas API
