⚡ 수파베이스 (Supabase) 연동 설정

수파베이스를 연결하면 여러 PC, 태블릿, 스마트폰에서 실시간 출석 데이터가 공유 및 영구 보관됩니다. (미설정 시 현재 브라우저의 로컬 저장소에 안전하게 유지됩니다.)

Supabase 대시보드 > Project Settings > API > Project URL
Project Settings > API > Project API keys > `anon` `public` 키
현재 상태: 로컬 브라우저 저장소 모드 (미연동)
💡 Supabase 테이블 설정 팁
프로젝트 폴더 내 supabase_schema.sql 파일을 Supabase SQL Editor에서 실행하시면 테이블 및 RLS 설정이 3초 만에 완료됩니다.
